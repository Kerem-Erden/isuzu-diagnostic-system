2. Gün — ESP32 projesi ve ilk firmware

Amaç: ESP-IDF ortamının gerçekten çalıştığını doğrulamak ve karta ilk firmware’i yüklemek.

Yapılacaklar:

get_idf
idf.py --version
ls -l /dev/ttyUSB*

Ardından ESP-IDF projesi oluşturulacak:

idf.py create-project isuzu_gateway
cd isuzu_gateway
idf.py set-target esp32
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor

İlk program:

ESP32 açıldığında başlangıç mesajı yazacak
Her saniye sahte RPM ve sıcaklık değeri gönderecek
Seri çıktının formatı belirlediğimiz protokole uyacak

Örneğin:

DEVICE:READY
RPM:750
COOLANT_TEMP:86
BATTERY_VOLTAGE:13.8

Burada kullanacağımız C konuları:

Fonksiyonlar
while döngüsü
değişkenler
string çıktısı
FreeRTOS gecikmesi
temel ESP-IDF loglama

Gün sonu çıktısı:

ESP32 karta yüklenmiş firmware ile USB üzerinden sürekli sahte araç verisi gönderiyor.

3. Gün — C#/.NET masaüstü uygulamasının temeli

Amaç: C# bilmediğin için kurs bataklığına girmeden yalnızca gereken temel uygulamayı oluşturmak.

Yapılacaklar:

.NET SDK kurulumu ve kontrolü
Visual Studio veya VS Code ortamını hazırlamak
Basit Windows masaüstü projesi oluşturmak
Seri portları listelemek
Port seçme kutusu hazırlamak
Bağlan / Bağlantıyı Kes butonları
Bağlantı durumunu göstermek

İlk arayüz:

Port: [ COM / tty seçimi ]

[ Bağlan ] [ Bağlantıyı Kes ]

Durum: Bağlı değil

İlk gün öğrenilecek C# konuları yalnızca:

değişken
metot
class’ın temel mantığı
event
try/catch
SerialPort

Henüz SQLite, MVVM, büyük mimari falan yok. Önce borudan su aksın.

Gün sonu çıktısı:

PC uygulaması mevcut seri portları görüyor ve ESP32’ye bağlanabiliyor.

4. Gün — ESP32 verisini PC’de ayrıştırma ve gösterme

Amaç: Haftanın ana entegrasyonunu gerçekleştirmek.

ESP32’den gelen:

RPM:750
COOLANT_TEMP:86
BATTERY_VOLTAGE:13.8

mesajları C# tarafında satır satır okunacak.

Sonra : karakterine göre ayrıştırılacak:

Key   = RPM
Value = 750

PC ekranında:

Engine RPM             750 rpm
Coolant Temperature     86 °C
Battery Voltage        13.8 V

gösterilecek.

Bu gün şunlar da yapılacak:

Bilinmeyen mesajı yok sayma
Eksik mesaj gelirse uygulamanın çökmemesi
ESP32 çıkarılırsa bağlantı hatası gösterme
UI thread’i dondurmadan veri okuma
Son alınan veri zamanını gösterme

İlk veri yapımız basit olabilir:

RPM:750

Ama gün sonunda gelecekte genişletmek için JSON veya daha sağlam mesaj formatının gerekip gerekmediğini değerlendireceğiz. İlk hafta sırf havalı diye JSON’a geçmek zorunda değiliz.

Gün sonu çıktısı:

ESP32’den gelen sahte RPM, sıcaklık ve voltaj verileri PC uygulamasında canlı güncelleniyor.

Bu, haftanın ana kilometre taşı.
